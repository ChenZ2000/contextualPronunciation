使用指南

项目主页 · English · 简体中文

本指南适用于上下文发音规范化 0.7.8。安装包从 GitHub Releases 下载。安装 .nvda-addon 后按提示重启 NVDA。支持的稳定版为 NVDA 2026.2，项目 CI 同时验证 2026.3beta2。

开始朗读

继续使用平时的普通话声音，正常阅读即可。默认规则会自动处理已支持的语境，例如“重吸收”的重复动作、“也给我盛了一碗”的装盛动作，以及“天兵和天将一起去吃饭”的并列名词。逐字和拼读模式保留原字。

处理过程在本机完成，插件不上传或记录你正在阅读的文本。

设置说明

打开 NVDA 设置 → 上下文发音规范化。点击“应用”或保存设置后，修改立即生效。也可以通过 NVDA 配置方案为不同任务保留不同设置。

设置 默认值 作用
启用上下文发音改写 开启 启用语音处理中的文本改写
纠正已支持的中文多音字 开启 应用已支持的普通话读音规则
规范化拉丁单词内的弯撇号 开启 在朗读时将 doesn’t 等单词内的弯撇号转换为直撇号
严格模式 开启 歧义文本保持原样；当前关闭后还会为“密钥、公钥、私钥”选择文读 yuè 的偏好

词典词组和有界词性、句法分析现已随中文纠正默认启用。旧配置中的“扩展词组库”值不再控制读音。词边界保护可区分“降调音频”的 diào 与“调音师”的 tiáo；遇到特定误读时，可以使用局部 keep 规则。

中文纠正会对所有声音和语言标签下的汉字指定普通话读音，请搭配支持普通话的声音。使用粤语、日语等汉字读法时，在相应的配置方案中关闭中文纠正。

自定义上下文模板

三个自定义输入框均支持多行：按 Enter 或数字键盘回车换行，也可直接粘贴多行内容；按 Tab 移到下一项，按 Ctrl+S 应用设置。输入框内按回车不会关闭设置窗口。

在“上下文模板”中，每行输入一条“前文[目标字:拼音]后文”规则。目标字为单个汉字，前文和后文至少填写一侧；普通文字按原样匹配，也可以使用已支持的占位符表示一类文本。

仙[乐:yuè]
[盛:chéng]{number}{container}
  • 仙[乐:yuè]：指定“仙”后面的“乐”读 yuè，放在“仙乐飘飘”等完整句子中也能匹配。写成 仙[乐:yue4] 效果相同。
  • [盛:chéng]{number}{container}：指定“盛”后面接数量和已列出的容器时读 chéng，例如“盛一碗”“盛两杯”。{number} 匹配最多 12 个中文或阿拉伯数字字符；{container} 匹配“碗、杯、勺、盆”等内置词项。
  • {space}：允许出现零到四个已支持的空白字符。例如 [盛:chéng]{number}{space}{container} 还可匹配“盛一 碗”。其他可用类别列在规则数据文件中。

希望保留原字，交给原语音或后续的 NVDA 语音词典处理时，将拼音改为 keep：

仙[乐:keep]

对同一语境，可用这条保留规则替换上面的 yuè 规则。每条模板只指定一个目标字，请按示例使用英文半角 []、: 和 {}。拼音支持声调符号或数字声调，ü 可写成 v，例如 lǜ 或 lv4。可用读音受插件已有同音映射范围限制；同优先级的个人模板出现读音冲突时，会保留原字。

自定义固定词规则

希望为一个确定的短语指定读音时，在“自定义固定词规则”中每行填写一条，用英文半角竖线 | 分隔三个字段：

仙乐|乐|yue4
盛汤|盛|keep

三个字段依次为“短语 | 目标字 | 读音 ID 或 keep”。第一行让“仙乐”中的“乐”读 yuè；第二行保留“盛汤”中的“盛”。读音 ID 使用数字声调，如 yue4、chang2、lv4。短语长度为 2–64 个字符，目标字必须在短语中恰好出现一次，同一短语和目标字的组合只填写一条。

同一位置同时匹配个人固定词规则和个人上下文模板时，固定词规则优先。通常为一处读音选择一种格式即可。

禁用规则与恢复设置

“禁用规则 ID”接受用英文逗号或换行分隔的内置规则标识。例如，填写 rowIndefiniteQuantity 可停用处理“多行”等不定行数的一条规则。可用 ID 记录在核心规则和句法框架中，也可在排查时由维护者协助确认。填写未知 ID 会在保存时提示错误。其他匹配规则仍可能影响同一个字；希望某个短语保留原字时，可使用局部 keep 规则。

撤销个人规则或恢复某条内置规则时，删除相应行或 ID，再点击“应用”。要恢复当前配置方案中的默认设置，请清空三个文本框，并开启四个复选框。若保存时提示规则无效，请按错误信息修改相应字段后再保存。

语音词典与 WorldVoice

插件先分析语音文本，再在 NVDA 词典和符号处理之后复查已支持的“和、边、邊、行”语境。选定的读音通过临时同音字发送给合成器，因此语音查看器可能显示替代字；文档、剪贴板和无障碍对象仍保留原文。

WorldVoice 6.2 的两种语言检测模式均有源码集成测试。它的词典输出可以继续参与读音纠正。Unicode 替换顺序由 WorldVoice 设置决定：“before”会先执行这些替换；“after”可能收到本插件已经改写的字符。后续替换必须接收原字时，可添加局部 keep 规则。源码测试使用隔离的声音替身，实际声音效果仍需试听。

可选盲文输出

在 NVDA 盲文设置中，将输出表选择为 Chinese common braille 2018 - contextual phrases (experimental)。它基于已有的 zhcn-cbs.ctb 表，增加经过审阅的固定语境修正。

此表独立于语音设置工作。个人语音模板、词库的读音判断和动态句法分析不会自动同步到盲文，当前覆盖范围限于表内的固定语境。“在光标处展开为计算机盲文”遵循 NVDA 原有行为，会绕过相应的上下文规则。选择原来的输出表即可恢复。

常见问题

情况 处理方法
已支持的词句仍然读错 确认已开启上下文改写和中文纠正，用完整原句复测。反馈时记录声音和版本。
粤语或日语读法被改变 在对应语言的 NVDA 配置方案中关闭中文纠正。
语音查看器显示了其他汉字 显示的是发给声音的临时发音文本，可到原文中确认实际字符。
自定义规则无法保存 检查目标字、拼音和所填字段的格式，按提示修改相应行。
关闭改写后仍有撇号保护 已安装的强制符号字典仍然有效；禁用或卸载插件并重启 NVDA 可停用全部功能。
键入单词回显时撇号表现不同 反馈完整键入过程和单词；较早发生的回显分段有独立的处理路径。

未知词、歧义句子或被语音命令分开的文本可能保留合成器自己的读法。不同声音的处理方式也会影响最终音频。

报告误读

请在 Issue 中提供：

  • 去除隐私信息后的完整句子及目标字。
  • 带声调的期望拼音，以及实际听到的读音。
  • NVDA 版本、插件版本、合成器和声音名称。
  • 相关设置、自定义规则及其他语音插件。
  • 如果方便，附上同字应读另一读音的对照句。

例如：“也给我盛了一碗——盛应读 chéng，实际听到 shèng。”保留完整语境有助于维护者复现结构判断。参与开发见贡献指南，词典出处见参考资料。
