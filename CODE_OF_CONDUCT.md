# Code of conduct

This project follows the [NVDA community code of conduct](https://github.com/nvaccess/nvda/blob/master/CODE_OF_CONDUCT.md), as required for Add-on Store submissions.

Treat contributors and users respectfully. Welcome different languages, disabilities and experience levels. Discuss technical behavior and evidence without harassment, personal attacks, discrimination or disclosure of private information. Respect accessibility when writing documentation and reporting issues.

The repository maintainer, ChenZ2000, moderates project discussions and may remove harmful content or restrict participation. Report concerns to the maintainer through GitHub; do not repost sensitive information in a public issue. Security vulnerabilities should follow [SECURITY.md](SECURITY.md).
