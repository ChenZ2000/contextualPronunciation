# Context-aware Pronunciation 0.8.1

## 简体中文

这是主分支候选版本；需要 NVDA 2026.2 或更高版本，原生测试另覆盖
2026.3beta2。GitHub 发布仍遵循[发布流程](../RELEASING.md)。

- “一点都不快乐”与“一点都不快乐。”中的“乐”明确选择 lè，经过句末
  符号处理后仍使用同一读音。“音乐”等 yuè 语境继续独立处理。
- “身上长、背上长了、胸前长了”、生长主体、长出某物、长得好看、
  长高／长大／长胖、长个子／个子长了，以及“各自长了”选择 zhǎng。
  “给我长脸了、长脸了”的争光义也选择 zhǎng。
- “头发很长、绳子长三米、长长的路、一张长脸、长脸型、拉长脸”
  选择 cháng。“头发长长了”依次为 zhǎng、cháng。词典中无歧义的
  生长、增长、校长、长辈等词的 zhǎng 也明确送往语音输出。
- 口语“懵逼、懵了、一脸懵”等沿用一声策略，补充“懵懵哒／噠”。
  单字“懵”、书面“懵懂／懵然”和字音讨论保留原文，继续由声库读音；
  不安装全局二声规则。
- 保留用户覆盖、禁用规则、原字符位置、逐字模式及语音项边界。
  “头发长了”“长脸的孩子”等缺少足够依据的歧义保持原文。

本版按共享语法识别论元和补语，不枚举所有完整句子。局部窗口为
96 个字符，另受现有 token、chart 和每项工作预算限制；不跨标点借用
另一句的语境。构造语料、原生集成和短／8K 性能检查覆盖已支持的结构，
不代表所有汉语歧义或声库都已解决。临时同音字只用于语音；文档、
剪贴板及盲文原字符保持不变。

候选安装包为 `contextualPronunciation-0.8.1.nvda-addon`，源码包为
`contextualPronunciation-0.8.1-source.zip`。本地候选与 main 推送不自动
发布 GitHub Release，也不构成商店更新。

## English

This main-branch candidate requires NVDA 2026.2 or later; native tests additionally
cover 2026.3beta2. Publication follows the [release process](../RELEASING.md).

- Lock lè in 快乐/快樂, with and without sentence punctuation, through NVDA's
  symbol and speech processing.
- Use shared bounded grammar for growing subjects, body locations, actual
  growth-product heads, complements, appearance, stature and distributive
  adverbs. 身上长、背上长了、胸前长了、长个子了、各自长了 select zhǎng.
  The honor idiom 给我长脸了/长脸了 also selects zhǎng.
- Length, measured extent and face-shape descriptions select cháng. In
  头发长长了 the stem selects zhǎng and the result selects cháng. Lock independently
  resolved lexical zhǎng in growth, elder and chief words.
- Extend the colloquial first-tone policy to 懵懵哒/噠; isolated 懵, literary
  forms and lexical mentions retain the voice's existing reading.
- Preserve user control, original offsets, spelling and speech-item boundaries.
  Unresolved 头发长了/长脸的孩子 remain unchanged. Reviewed contribution templates
  can now be disabled by ID.

The grammar uses a 96-character window with existing token/chart/item limits.
Independent constructed cases, native integration, reproducible fixtures and
short/8K timing gates cover supported constructions, not all Chinese ambiguity
or every voice. Preparing local packages and pushing main do not publish a
Release or submit a Store update.
