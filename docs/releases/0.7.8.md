# Context-aware Pronunciation 0.7.8

## 简体中文

本版升级离线中文多音字纠正，并整理用户与贡献者文档。需要 **NVDA 2026.2 或更高版本**；稳定 API 声明为 2026.2，原生 CI 另覆盖 2026.3beta2。

### 读音与句法

- 中文纠正启用时始终加载词典与有界语法，移除“启用扩展词组”选项。
- “重装／重裝”默认按重新安装读 **chóng zhuāng**，保留明确的重型装备等用法保护。
- 扩展“转”的旋转、绕逛与转交义判断，结合名词中心、主宾语、接收者、受益者、目的从句和补语。
- 覆盖“螺丝刀转呀转、引擎会转、发电机转起来”等结构；重复谓词共享论元。“把螺丝刀转给经理”等转交用法保留三声。
- 共用重复构式也用于“盛、量、系”的现有语义框架。补充出差数量／时长、宿的夜数／星宿及“倔强”两个音节的处理。
- 用户规则、keep、原文位置与解析工作预算继续生效。处理始终离线，文档原文保持不变。
- “装盛／裝盛”默认读 chéng；“盛装动作、盛装到容器里”等容纳义使用 chéng，“盛装赴会、身穿盛装”保留原读音。
- “弹……琴／彈……琴”依据动宾关系选择 tán，支持数量、所属关系和嵌套修饰语，例如“弹了123遍琴、弹小明昨天买的那架钢琴”。
- 修复设置中的三个自定义输入框：回车换行、多行粘贴与保存，保留 Tab 导航和 Ctrl+S 应用设置。

### 文档与验证

用户设置和排查集中在中英文使用指南，安装帮助由同一份指南生成。开发架构、贡献规则和发布流程合并整理；旧过程报告及本地 AI 指令不进入公开包。

发布工作流要求当前提交的两个原生 NVDA CI 目标通过，并验证可复现包与官方清单格式。此引擎版本的本地 Ting-Ting 核验包含 118 组最终朗读、120 组边界和 130 组句子对照。音素／PCM 一致性不等于所有声音和所有语境均正确；未知或有歧义的结构仍可能保留原字。

下载 `contextualPronunciation-0.7.8.nvda-addon`，安装后按提示重启 NVDA。源码为 `contextualPronunciation-0.7.8-source.zip`，使用 `SHA256SUMS` 核验下载。

## English

This release expands offline Mandarin polyphone correction and consolidates current documentation.

- Always enable dictionary and bounded grammar with Chinese correction; remove the extended-lexicon checkbox.
- Default 重装 / 重裝 to chóng for reinstall, while preserving explicit heavy-equipment expressions.
- Select rotation, roaming and transfer senses from argument heads, recipients, beneficiaries, purpose clauses and verb complements. Add dictionary-derived mechanical/tool candidates and shared arguments for repeated predicates such as 转呀转 and 转了又转.
- Reuse repetition with the existing 盛, 量 and 系 frames; improve counted work trips, 宿 contexts and both syllables of 倔强.
- Keep user overrides, original offsets, offline processing and work limits. Ambiguous or unsupported contexts can still remain unchanged.
- Default 装盛 to chéng and recognize containment action nominals and container goals; preserve attire contexts. Select tán for 弹…琴 from parsed instrument objects, including quantities, possessors and nested modifiers.
- Fix multiline custom-rule input: Enter inserts a newline; Tab navigation and Ctrl+S apply remain available.
- Generate installed help from current bilingual user guides. Exclude local AI instructions and development-session reports from published source and packages.

Requires NVDA 2026.2; native CI additionally tests 2026.3beta2. Publication requires both native targets on this exact commit, reproducible archives and official manifest/schema checks. Local Ting-Ting homophone-anchor tests cover the listed engine version; they do not certify all voices or open-domain accuracy.

Install the `.nvda-addon` and restart NVDA. The matching source bundle, checksums and CI verification are attached. **This is a GitHub release only; Store updates remain on hold pending approval of the first submission.**
