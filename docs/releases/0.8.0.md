# Context-aware Pronunciation 0.8.0

## 简体中文

需要 **NVDA 2026.2 或更高版本**；CI 另覆盖 2026.3beta2。本版修复“懵”的过度规范化，不再为每个未受保护的“懵”默认设置一声。

### 读音调整

- **只对有依据的口语用法选择一声 mēng。**“一脸懵、一脸懵逼、懵圈、懵了、被问懵、懵得说不出话、越想越懵”等，以及可由这些语法结构推导的新组合，继续命中。无需逐条列出完整主语、宾语与补语。
- **单字与非口语用法保持原文。** 单独的“懵”、带标点或引号的单字、“懵的读音、输入懵”等字词提及、“懵懂、懵然、懵头转向”等书面用法不再被广泛默认覆盖。保持声库原有读音，不将全部非口语词强制改为二声。
- 口语一声输出采用“擝”（U+64DD），不再使用可能被读成二声的旧替代字“蒙”。这是临时语音文本；文档和剪贴板不变，Speech Viewer 可能显示替代字。
- 保留个人固定词、模板、`keep`、禁用规则和逐字／拼读模式的优先级及边界。可停用 `colloquialMeng`。不跨分开的语音文本项重建短语。
- 0.7.9 的“折腾、倒腾、捣腾、闹腾、掀腾”等整词轻声保留策略继续有效，本版不扩大“腾”的全局读音覆盖。

### 验证与限制

新增按语言学结构构造的正例、反例和混合文本，覆盖简繁体、默认／扩展引擎、严格／非严格模式、用户覆盖、原字符位置、命令边界及真实 NVDA 符号处理。独立评估会去重并记录实际用例数，不把生成用例通过率当作自然语料准确率。新增短文本中位数 200 微秒、长文本中位数 30 毫秒的强制性能门禁；原有性能预算和基线比较保持不变。

匹配采用有限局部窗口，不能穷尽专名、所有新造口语、歧义或长距离依存。证据不足则保留原文。“擝”是生僻字，需目标声库支持；文本测试和字音资料不能替代实际试听。具体设计、来源、例句与验收方法见[口语“懵”的语境识别](../COLLOQUIAL_MENG.md)。

安装 `contextualPronunciation-0.8.0.nvda-addon` 后重启 NVDA，分别试听单字、书面词、口语短语、混合句和逐字导航。发布时的源码包为 `contextualPronunciation-0.8.0-source.zip`，可用附件 `SHA256SUMS` 校验。维护者确认试听无误且 main 同一提交的两个原生 CI 目标均通过后，按[发布指南](../RELEASING.md)触发 **Publish release from main**；准备候选包不自动发布，不覆盖旧版附件，也不自动提交商店。

## English

Requires **NVDA 2026.2 or later**; CI additionally covers 2026.3beta2. This release fixes over-normalization of 懵 by removing the unconditional first-tone fallback.

### Pronunciation changes

- **Select first-tone mēng only with positive colloquial evidence.** 一脸懵, 一脸懵逼, 懵圈, 懵了, 被问懵, 懵得说不出话, 越想越懵 and new combinations of supported grammatical structures remain covered without enumerating every complete sentence.
- **Preserve isolated characters and non-colloquial uses.** Bare or individually quoted 懵, lexical mentions such as 懵的读音 / 输入懵, and reviewed literary forms such as 懵懂 / 懵然 / 懵头转向 keep the original text and voice reading. This does not impose second tone on all preserved words.
- Render matched speech with 擝 (U+64DD) instead of the polyphonic 蒙 used by the published 0.7.9 package. Documents and clipboard content remain unchanged; Speech Viewer can display temporary homophones.
- Retain personal literal/template priority, `keep`, disabled rules, spelling mode and speech-item boundaries. Disable `colloquialMeng` to suppress this policy. Separate speech text items are not joined to recover a phrase.
- Keep the existing whole-word neutral-tone policy for 折腾, 倒腾, 捣腾, 闹腾 and 掀腾; this release does not introduce a blanket reading for 腾.

### Validation and limitations

Independent constructed positive, negative and mixed examples cover simplified/traditional text, default/extended engines, strict/non-strict settings, personal rules, original offsets, command boundaries and real NVDA symbol processing. The evaluator deduplicates and reports exact counts; passing a generated inventory is not measured natural-corpus accuracy. A new fail-closed performance stage enforces short/long input medians of 200 microseconds / 30 milliseconds; existing global budgets and baseline comparisons remain unchanged.

The matcher uses bounded local evidence, not exhaustive semantic understanding. Unfamiliar names, ambiguity, novel constructions and distant dependencies can remain unchanged. The rare renderer 擝 must be supported by the voice; text and lexical tests are not an acoustic certificate. See the [linguistic design, sources and listening checks](../COLLOQUIAL_MENG.md).

Install `contextualPronunciation-0.8.0.nvda-addon` and restart NVDA. Check isolated characters, literary and colloquial phrases, mixed sentences and character navigation. The published source bundle is named `contextualPronunciation-0.8.0-source.zip`; verify release downloads against `SHA256SUMS`. Only after maintainer listening acceptance and both native CI targets succeeding for the exact main commit should **Publish release from main** be triggered as described in the [release guide](../RELEASING.md). Candidate preparation does not publish, overwrite older assets or submit to the Store.
