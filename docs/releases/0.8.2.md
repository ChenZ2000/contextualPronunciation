# Context-aware Pronunciation 0.8.2

## 简体中文

这是 main 候选版本，支持 NVDA 2026.2，并测试 2026.3beta2。
发布仍遵循[发布流程](../RELEASING.md)。

- “长个、长个了、长个了没、长不长个、长不了个、长点个吧”中的
  “个”按完整名词边界识别为身高省略词，选择 zhǎng；不凭相邻字猜测。
- “个头、个儿、个子、身高、身量、块头”等实际身高中心语及其倒装、
  否定、疑问、可能补语和体标记参与统一分析。“长个新的痘痘”的“个”
  是量词，中心语是痘痘。“长个未知东西、长个了个包”等保持原字。
- 从固定词典与 HowNet 词义投影植物、动物、身体部位、身高和能力等
  名词候选，保留词义／记录 ID。“菖蒲长了”选择生长义；
  “菖蒲的照片长了”按照片中心语选择长度义。“长胖一点”独立识别数量
  补语；“给我长不了脸、长一长脸”使用争光义与共享谓词形态。
- “长我两岁、他比我长三岁、比妹妹长几岁、年纪长了”使用年龄词义与
  年龄差补语；“长三”不能截断谓词和数词。年龄修饰语不会把读音传给
  照片等实际中心语，“寿命比我长三年”仍按时长选择 cháng。
- 设置项“严格模式”及运行时模式分支已移除。插件统一自动判断；旧
  配置项不影响语音或原文注音，不需要删除配置。已有用户规则、禁用
  规则、逐字模式、原字符位置和语音项边界保留。
- “密钥、公钥、私钥”的文白读音变体保持原字，个人规则仍能指定 yuè。
  “快乐”的 lè 和口语“懵”的一声策略继续回归验证。

解析仍是离线、有界的局部语法。生成的构造语料覆盖上述结构，
不代表自然语料准确率或所有汉语歧义均已解决。
“头发长了”“长了一大截”等缺少独立依据的歧义仍保留声库处理。
安装包名为 `contextualPronunciation-0.8.2.nvda-addon`；准备候选与推送
main 不会自动创建 GitHub Release 或提交商店更新。

## English

This main candidate supports NVDA 2026.2 and additionally tests 2026.3beta2.

- Recognize clipped stature 个/個 at complete nominal boundaries, full semantic
  stature heads, questions, negation, potential complements and aspect placement.
- Distinguish clipped nouns from classifiers with overt objects. Project
  growing/body/stature/development senses from pinned sources with record IDs;
  select actual heads and attachments. Result quantities and honor constructions
  share bounded morphology rather than runtime sentence inventories.
- Recognize age nouns, age-difference quantities and actual human comparands;
  protect length/duration competitors and modifiers with a different head.
- Remove strict mode from the UI, schema, options and reading APIs. Legacy profile
  values have no effect. A single automatic policy combines lexical and grammatical
  evidence and preserves unresolved variants; explicit user overrides still apply.
- Retain spelling, speech-item boundaries, original offsets and speech/braille
  decision parity. Expand constructed tests, renderer fixtures and timing gates.

Finite constructed coverage does not establish universal Chinese disambiguation,
natural-corpus accuracy or support in every voice. Publication follows the
[release workflow](../RELEASING.md); a local candidate or main push is not a release.
