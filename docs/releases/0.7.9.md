# Context-aware Pronunciation 0.7.9

## 简体中文

本版包含 [PR #4](https://github.com/ChenZ2000/contextualPronunciation/pull/4) 的口语“懵”纠正和“腾”轻声词处理。需要 **NVDA 2026.2 或更高版本**；CI 另覆盖 2026.3beta2。

### 读音调整

- “一脸懵逼、懵了、懵圈、看懵了、懵得说不出话”等口语表达默认选择一声 **mēng**，也覆盖未逐项列出的新语境。这是口语兼容策略，不表示“懵”的规范字音改为一声。
- “懵懂、懵懵懂懂、懵里懵懂／懵裡懵懂、懵然”等审定书面词保留原字，避免覆盖其三声 **měng**。保护词表和资料来源见[参考资料](../REFERENCES.md#简体中文)。需要关闭口语默认时，在“禁用规则 ID”中填写 `colloquialMeng`；个人 `keep` 和读音规则仍可覆盖特定语境。
- 为“折腾、倒腾、捣腾、闹腾、掀腾”及相应繁体词形记录轻声 **teng5**，同时保留完整词形交给语音合成器处理，避免先改成“遮腾、导腾”而破坏整词识别。
- 增加跨词边界保护，例如“曲折／腾挪”“打倒／腾空”不会因相邻字组成“折腾、倒腾”而误标轻声；“折腾空调、倒腾空间、倒腾飞机”仍按完整轻声词处理。

### 验证范围与限制

新增回归覆盖简繁体、严格模式、用户规则、禁用规则、语音决策与注音的对应关系，以及原文位置和词边界。它们验证规则输出，不构成新增声音的音频实测。

轻声读音记录可供注音接口使用；朗读时保留整词，由当前语音合成器决定实际发音。本版不向所有合成器强制发送轻声音素，也不保证所有声音都能正确读出轻声。书面词保护需要相关字位于同一段输入文本中，不能跨语音命令或分开的语音文本项恢复上下文。

下载 `contextualPronunciation-0.7.9.nvda-addon`，安装后按提示重启 NVDA。源码包为 `contextualPronunciation-0.7.9-source.zip`，可用发布附件中的 `SHA256SUMS` 核验下载。

## English

This release includes the colloquial 懵 and neutral-tone 腾 changes from [PR #4](https://github.com/ChenZ2000/contextualPronunciation/pull/4). Requires **NVDA 2026.2 or later**; CI additionally covers 2026.3beta2.

### Pronunciation changes

- Default colloquial 懵 to first-tone **mēng** in 一脸懵逼, 懵了, 懵圈, 看懵了 and other contexts, including expressions outside a finite phrase list. This is a colloquial compatibility policy, not a change to the character's normative dictionary reading.
- Preserve 懵懂, 懵懵懂懂, 懵里懵懂 / 懵裡懵懂, 懵然 and other reviewed literary forms to retain third-tone **měng**. See the [references](../REFERENCES.md#english) for the protection inventory and sources. Disable the colloquial default with rule ID `colloquialMeng`; personal `keep` and reading rules still take precedence for matching contexts.
- Record neutral-tone **teng5** for 折腾, 倒腾, 捣腾, 闹腾, 掀腾 and their traditional forms. Keep each complete word for the synthesizer instead of rewriting its first syllable to a homophone such as 遮 or 导.
- Protect boundaries such as 曲折 / 腾挪 and 打倒 / 腾空 from false neutral-tone annotations, while retaining valid complete words in 折腾空调, 倒腾空间 and 倒腾飞机.

### Validation scope and limitations

New regressions cover simplified and traditional text, strict mode, user overrides, disabled rules, speech decisions and annotations, original offsets and word boundaries. They validate rule output and do not constitute new voice audio measurements.

The annotation API exposes neutral-tone readings; speech preserves complete words and leaves their acoustic realization to the selected synthesizer. This release does not force neutral-tone phonemes in every engine or guarantee pronunciation across all voices. Literary-word protection requires the relevant characters within one input text item; context is not reconstructed across speech commands or separate text items.

Install `contextualPronunciation-0.7.9.nvda-addon` and restart NVDA. The matching source bundle is `contextualPronunciation-0.7.9-source.zip`; verify downloads using the release's `SHA256SUMS` attachment.
