# Context-aware Pronunciation 0.7.4

First public repository release of the offline NVDA Mandarin pronunciation add-on. This release preserves the 0.7.3 runtime, including structural handling of 下边缘, 唱和说, 多行, quantified objects and coordinated subjects, with a queue-stage check after dictionaries and symbols.

- Requires NVDA 2026.2. The stable manifest declares that tested stable API; 2026.3beta2 remains an additional development CI target.
- Adds reproducible public builds, source archives, SHA-256 checksums, maintainer/repository metadata, bilingual user guides and community contribution documents.
- Keeps the extended lexicon and braille enhancements experimental. Supported examples and 1,154 targeted grammar cases do not imply complete Chinese accuracy or support for every voice.
- Runtime processing is offline. Homophones are used only in temporary speech text; Speech Viewer can display them. Original documents are unchanged.

Download `contextualPronunciation-0.7.4.nvda-addon` to install. `contextualPronunciation-0.7.4-source.zip` contains corresponding source and licensed data snapshots. Verify downloads against `SHA256SUMS`.

Public CI runs without proprietary voices. Its success confirms the listed code/data/integration checks, not listening acceptance on all synthesizers. Add-on Store submission and approval are separate from this GitHub Release.
