# 0.7.2：省略宾语与主谓连接

本次解决的是成分组合和分词歧义，未将反馈原句加入替换词表。

## 分析流程

NVDA 公开语音过滤器取得当前文本片段后，沿用同一套裁决链：用户设置与明确词汇读音优先；需要上下文时，再做有界分词、名词短语分析、形态分析和主谓依赖判断。原文位置始终保留，最后只向合成器提交同音映射后的朗读文本。

不累计后续文本，不跨语音命令、控制字符或句子标点拼接上下文。词典在加载时驻留内存，朗读时不联网、不查磁盘。单次成分分析最多 512 字、256 个词元，嵌套深度 16；保留既有图表与单个语音项工作预算。谓语起始结构另限制为 32 个词元。超限、未知结构或证据冲突时保留原字。

## 本次结构变化

- `盛 + 了 + 一 + 碗 + [省略内容]`：量词有容器义且数量成分完整，可以作为表层宾语中心；不再必须出现饭、汤等名词。依赖记录使用真实的“碗”的位置，不虚构被省略的词。内容物不必是食物，因此不将量词一律标成食物义。
- `天兵 + 和 + 天将 + 一起 + 去吃饭`：并列名词成分与后续谓语连接，输出 `conj`、`nsubj` 和 `advmod` 关系。反向顺序及有定语的并列成分使用同一分析。
- 名词“将”的竞争分析需要人员量词、明确定语或来源明确的名词构词证据。后接谓语时，不能仅凭前文有“兵”就把将来时“将”改成 jiàng。
- “一起／一同／一齐”等词保留副词分析，避免被拆成数词和量词；出现“训练有素的士兵”时，比较“的士／兵”与“的／士兵”的跨词边界名词证据。“的士”自身仍可作为词语保留。
- 对“天将／要去吃饭”“天将／会一起出发”这类跨边界组合，允许句法重新评估词典中的将来助动词分词；仍须完成并列名词和谓语分析，用户保留与禁用设置优先。普通的“老师将要去吃饭”保持 jiāng。

词典构词投影由构建脚本从固定版本资料生成：对末尾读作 jiang4 的军职名词，以及有两个军事名词成分的四字词，保留已对齐读音与来源条目 ID。比如“天兵天将”“虾兵蟹将”所包含的名词成分可参与新的句法组合。运行时不按反馈整句匹配。这是词汇知识加受约束的符号语法，不是覆盖所有汉语语义的完整语言模型。

## 来源与可复现性

- [CC-CEDICT](https://www.mdbg.net/chinese/dictionary?page=cedict)：词形、对齐读音及名词构词来源，CC BY-SA 4.0。
- [开放词典汉语字典 KFCD](https://github.com/kfcd/hyzd)：字义、词性与读音证据，CC BY 3.0。
- [OpenHowNet](https://github.com/thunlp/OpenHowNet)：容器量词、人员量词和军事名词义原，MIT。
- [cppjieba 固定版本词典](https://github.com/yanyiwu/cppjieba/tree/b3602bef7d1f67521a61788a74fb5801a0e62cd3)：分词候选及词性备选，MIT。
- [教育部“盛”字释义](https://dict.concised.moe.edu.tw/dictView.jsp?ID=32353&la=0&powerMode=0)：用于核对 chéng 的容纳、装盛义；未批量抓取并打包其释义。

原始输入散列在 `tools/build_grammar_data.py` 固定。`python tools/build_grammar_data.py --check` 验证编译数据可重复生成。新名词构词投影保存在 `grammar_lexicon.json` 的 `generalNouns`，每个词带原始记录 ID；保留原有许可说明。

## 验证范围

1036 个项目自编的定向案例包含原有 737 例和新增 299 例；其中两例原先因后接谓语而保留原字，现在依据补全的结构分析改为 jiàng。覆盖时体、数量、量词、形容词、后续谓语、正反并列顺序、简繁体、长修饰语、将来时反例、未知词、语音命令边界以及用户保留设置。

这些案例的通过率表示定向回归覆盖，不代表开放域汉语的准确率。性能统计只计本地发音处理，不包含合成器启动、声音合成、播放队列或音频设备延迟。最新运行结果和可安装包以 artifacts 与 dist 中本版本的验收记录为准。
