# 0.7.0：组合句法、长修饰语与“重＋动词”

本轮重写了结构分析底层，并接入现有 NVDA 公开语音过滤器与共享注音 API。默认开启，不要求启用实验性扩展读音词库。代码和安装包版本为 0.7.0。

## 已实现的变化

- “重”的再次义使用独立动词词法证据组合，支持重转、重编译、重转码、重剪辑、重配音、重排序等未枚举组合。不会给所有“重＋动词”无条件标 chó​ng；已有 zhòng、同词异读和不明复合词阻止泛化。
- 增加词边界竞争：较短的“重压”不能切开独立动词“压缩”，因此“重压缩”可按“重＋压缩”解释。左右词边界、原有保护、用户 keep 和禁用规则仍参与裁决。
- 名词短语改用单次分析内的记忆化成分图，支持嵌套领属、关系从句、并列形容词、并列谓语和方位结构；保留 obj、nmod、amod、acl、conj、compound、advmod 的原文偏移。
- “量住在那条非常安静的街道旁边的小名的身高”中，“安静”关联“街道”，“住在……”关联“小名”，最终宾语中心词为“身高”。
- 支持显式“把／将＋宾语＋状语＋动词”前置宾语，如“把小名的身高再仔细地量一下”“把刚煮好的红豆粥盛进碗里”。
- 长修饰语不再受原 48 字、24 词、3 层限制。结构窗口为 512 字、256 词，递归预算为 16 层；标点、符号、换行和语音命令仍是边界。完成的宾语不会仅因后续句子很长而丢失。

## 验证和复现

`tests/grammar_cases.py` 提供 105 条项目编写的定向语料：53 条应标音，52 条应保留。包括长句、嵌套结构、简繁字形、词义反例与命令边界。它们没有加入运行时整句规则。

与修改前保存的 0.6.1 源码实际运行比较：两种词库模式下，旧版命中 10/53 个正例，新版命中 53/53；52/52 个保护例两版均保留。该结果是针对本次问题编写的回归结果，不能外推为任意汉语句子的准确率。其他测试还覆盖组合矩阵、词头替换、嵌套依存偏移、原文 UTF-16 偏移、用户覆盖、无运行时 I/O 和工作预算。

```powershell
python tools/build_grammar_data.py --check
python tools/evaluate_grammar.py
python tools/benchmark_grammar.py
python tools/pronunciation.py "量住在那条非常安静的街道旁边的小名的身高"
python scripts/run_tests.py
python scripts/run_regression.py --native --vocalizer --release
```

`artifacts/grammar-evaluation.json` 记录逐例决定；`artifacts/grammar-performance.json` 记录单次调用中位数、p95、p99 和最大值，分默认／扩展模式。`artifacts/performance-report.json` 保留原性能门禁；`artifacts/startup-report.json` 单独测启动与 Python 内存。已有声学 fixture 增加重转、重编译、重压缩、并列定语、嵌套从句及前置宾语，并需重新渲染，不能只更新哈希沿用旧音频。

## 延迟与适用范围

热路径用不可变词典索引、短产生式快速路径和每个语音项一次的字符预筛选；不保存跨调用朗读文本。普通短语使用 Python 已可达到很小的实测开销，所以本轮没有增加需要按 NVDA 架构分发的本地 DLL。底层 C/C++ 并不能消除词义歧义，也不能实现物理意义上的零延迟。

每次成分分析最多 4,096 个图状态、8,192 个按跨度计费的工作单位；每个语音项共用 65,536 个工作单位。触及预算时撤回不完整的结构判断，其他明确词条及快速动词组合继续生效。预算是计算资源限制，不是读音置信度。专门的病理嵌套长文本门禁防止很长的重复输入在同步朗读线程耗时失控。512 字与预算均是明确限制，不能称为无限长句完全理解。

这是用于读音的可扩展符号成分分析器，仍不是任意汉语全文的统计依存模型或完整语义理解系统。现有通用框架主要新增“重”的重复谓语和“盛／量／系”的论元结构；其他多音字仍依赖既有审阅规则、模板和可选读音词库。省略、指代、隐喻、专名、未收录新词、真正多解的词义仍可能弃权或误判。特别是脱离语境的“重读／重载／重装”不应强行统一为一个音。引擎只为有证据的目标字发音，不会凭“重转”的重字决定“转”的所有词义读法。

新增动态语法进入共享注音 API，保留原字；没有动态接管 Liblouis 静态盲文表。安装新版需要按 NVDA 提示重启；开发构建和离线验收不改变活跃 NVDA 的声音或配置。声学回归仅证明所测引擎、声音、文本与同音锚点的音素一致性，人工试听和未测声音仍不在此保证内。
