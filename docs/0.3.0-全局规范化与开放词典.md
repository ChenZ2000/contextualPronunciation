# 0.3.0 全局规范化与开放词典设计

本版目标是让同一个普通话上下文裁决器服务所有语音，移除按引擎／声音／语言标签选择策略的运行时代码。跨语音共用算法与“所有语音都保证发出正确音素”是两件事；NVDA 的文本过滤扩展点并不赋予不支持拼音／音素接口的合成器强制读音能力。

## 一个公开入口，一次裁决

公开 `filter_speechSequence` → 缓冲可迭代序列一次 → 跳过逐字模式 → 词内撇号规范化 → 原文位置上的规则裁决 → 统一同音字映射 → 返回语音序列。

删除了生产包的 `renderers.py`、`worldvoice.py`，不再调用 `getSynth`、读取 voice/language 或注册 synthChanged。所有字符串片段执行相同规则，语言命令只是透传对象。旧代码可从 0.2.0 源码包恢复，未修改 NVDA 或 WorldVoice 安装文件。

生产包不含探测逻辑。测试工具需要选择本机合法声库并记录引擎身份，以便复现声学结果；这不构成运行时声音白名单。cheng2 全局映射为“呈”，不再依据 Ting-Ting 名称选择“成／呈”。

列表无改动时返回原对象；生成器只消费一次；本插件内部异常返回已缓冲原序列。上游生成器本身若迭代失败，无法恢复已丢失数据，异常交回上游，不伪装为成功。上下文不跨命令、独立字符串或后续朗读请求，以避免索引错位和延迟等待。

热路径只访问内存中的有界规则和索引。扩展库默认关闭，未启用时不构建大索引。最大词长 32，双向匹配采用两字索引；模板数字和空白都有上限，无联网、无模型、无数据库查询。

发布前性能分析发现，原语音路径为只需少量替换的长文本建立了大量仅供全量注音使用的对象。因此增加语音输出投影：仍用完整词典双向分词，保留所有阻断词；分词裁决完成后，仅为有语音候选的词分配注音。共享 API 默认继续返回完整注音，逐词穷举测试证明投影后的语音决策与原完整结果中的语音部分相同。不缓存用户文本，不删词、不缩短语境，也不放宽性能阈值。

## WorldVoice 6.2 顺序证据

回归固定 [WorldVoice 6.2](https://github.com/tsengwoody/WorldVoice/releases/tag/6.2)，提交 `318bc90bf8a7af9e901bb43cd7da036533f443ea`。其 [公开管线注册](https://github.com/tsengwoody/WorldVoice/blob/318bc90bf8a7af9e901bb43cd7da036533f443ea/addon/synthDrivers/WorldVoice/pipeline/__init__.py) 将词典过滤器排到开头；`before` 检测在该公开阶段，`after` 检测在后续 speak 阶段。

因此本插件只需注册普通公开过滤器。测试执行真实 WorldVoice 管线、语言检测以及原始 speak 方法体，使用隔离配置和替身声音。额外测试读取本机安装 6.2 的同一批源码，核对标准化换行后的内容与固定提交相同。不会读取用户词典、加载专有引擎或保存配置。

字典 `测试词 → 仙乐飘飘` 两种时序都先执行一次，再由本插件得到 `仙月飘飘`。Unicode 替换则有时序差异：前置 `盛 → 胜` 会得到“胜汤”；后置时本插件先得到“呈汤”，不再命中“盛”。0.2.0 私有适配器曾试图统一该时序；0.3.0 删除它，以服从公开接口与全局策略。局部 `[盛:keep]汤` 可以保留原字给后续阶段，但若前置阶段已替换原字，本插件不会猜回。

实际活跃 NVDA 的最终声音和音频还需试听验收。安装目录存在、源码测试通过或磁盘配置指定某合成器，都不能证明当前活跃声音已经测试。本次桌面自动化通道不可用，未绕过它调用其他 UI 工具，也未替用户更改设置。

## 数据源和许可选择

使用 [CC-CEDICT](https://www.mdbg.net/chinese/dictionary?page=cedict) 2026-09-07 快照（CC-BY-SA-4.0）、[KFCD 开放汉语字典](https://github.com/kfcd/hyzd/tree/04987755b16264636c01d28df4d96fa14dadd210) 固定提交（CC-BY-3.0）和 [Unihan 17.0.0](https://www.unicode.org/reports/tr38/tr38-39.html) 字音交叉核对。原始 SHA-256、网址、许可和处理方式由 `data/dictionary-sources.json` 固定。

KFCD 有逐字义拼音、繁简字形、例词和释义，补足只靠词组拼音表缺少字义出处的问题。它也保留地区差异与多种读音，不应冒充国家规范审音全集。开放访问不等于可重新分发，不能仅因网页能打开就整体导入。

本次查阅但未导入：`mozillazg/phrase-pinyin-data` 的第三方词典来源许可链尚需逐项确认；`mapull/chinese-dictionary` 上游提示部分原始来源无法确认；Wiktionary／Kaikki 可作后续独立解析器任务，但地区标签、多音释义和对齐仍需专门测试。项目目录中的可访问仓库不等于有权打包其所有上游数据。

## 三层数据库

1. 原始快照：`data/sources` 保留 CC-CEDICT、KFCD 简体和原始 TSV、Unihan 及许可。固定版本离线复现，不随朗读联网更新。
2. 规范源记录：`data/dictionary-records.jsonl.gz`，131,436 条，保存来源行、稳定 ID、字形、原始拼音、数字调拼音、释义、例词和许可。可用 `tools/build_dictionary_database.py --query 盛汤` 查询；`--sqlite 新路径` 构建本地索引且拒绝覆盖文件。
3. 运行索引：`lexicon_zh_CN.json` schema 2，110,692 个词头，不含释义。89,410 个有完整或部分读音、21,282 个阻断；原文位置上的 `?` 在 API 中变成 None，绝不填成默认音。

规范记录中 CC-CEDICT 的 `readings` 是词内字符对齐序列；KFCD 的 `kind=characterSense` 中 `readings` 是该字义的候选读音集合，不能当成例词全词注音。所有记录仍带 kind、readingStatus 和 rawPinyin，消费者必须区分。

KFCD 贡献 856 个新增部分注音词头。冲突按位置求共识，保留其他有依据的字音；已存在的专名／多音整词阻断不能被单个字义“救活”。只接受目标恰好出现一次、2–32 个纯汉字的例词，含省略、整句或重复目标的例子留待人工审阅。保存 `wordSources` 以追溯到原字典行。

892 个多读音目标字、448 个满足当前自动语音候选政策的字和 4,797 个可渲染词头都是候选统计，不是完成了相应数量的实际误读修复。默认六字族保护优先，广覆盖库仍为实验性开关。

## 拼音、语音和盲文的分离

读音数据表示词典本调，不代替引擎处理三声变调、轻声韵律或连读。规则声明 `[字:拼音]`，共享 API 输出原字、读音、来源和原文偏移；语音映射最后才产生临时同音字。原无障碍文本与剪贴板不变，但 Speech Viewer 可能显示语音文本。

国家通用盲文 2018 输出表仍为基于原文的固定上下文叠加，418 条，未把新增大库无审阅地自动译成盲文。部分注音中的未知字位必须空缺，而不是写出假定拼音。完整分词连写、动态读音与 Liblouis 原文映射仍是独立开发任务，不能借替换汉字伪装实现。

## 回归和发布门禁

单元测试穷举编译词库的每一个词头，并验证不选异读首音、冲突次序不敏感、部分位置弃权、阻断不回退、源数据库可复现和逐条许可。运行包 AST 检查禁止导入合成器模块或读取当前引擎／语言，以防以后重新出现引擎白名单。

另有句中两次“盛”的组合矩阵、全 Unicode 标点／符号边界、WorldVoice before/after、配置迁移、原生 NVDA 语音链、实际 Liblouis 点位和光标路由测试。严格显示保护测试沿用 NVDA 官方行为，不主动关闭幕帘或颜色滤镜。

VE 回归使用 265 组、925 次离线渲染与独立锚点。eSpeak 和系统 SAPI 各 15 组附加探测：音素／PCM 不等同人工辨音，尤其 eSpeak 缺少完整普通话词典时，某些独立锚点自身缺词。附加探测不把锚点不等强判成误读，也不因此反向调整例子以“刷绿”。

CPP 测试集来自 [Park 与 Lee 的 g2pM 研究](https://arxiv.org/abs/2004.03136)。仅作为离线外部标注审计，不训练、不按测试标签调规则；词库与基准可能有词汇重叠。公开覆盖率、条件一致率、弃权和分歧明细，不宣称开放域全准确。声学正确性另需试听。

`scripts/run_regression.py --native --vocalizer --release` 执行严格本地发布流程；加 `--installed-worldvoice 路径 --cross-engine-probes` 包含本机附加验证。校验日志、源码、fixture、测试和原生 DLL 的哈希，重新构建安装包与源码包两遍并比较字节。最新结果见 `artifacts/release-verification.json`，未完成的人工项目在其中显式列出。
