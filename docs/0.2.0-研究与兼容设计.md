# 0.2.0 研究与兼容设计

研究日期：2026-09-15；目标 NVDA 2026.2、WorldVoice 6.2、普通话及国家通用盲文 GF 0019-2018。安装说明和当前限制见根目录 README。旧报告的功能范围不代表本版。

## WorldVoice 根因与修复

旧自动适配仅允许 vocalizer_expressive2/Ting-Ting，WorldVoice 对外标识不在名单内。但简单加入白名单仍不充分：其 Filter 返回 generator，WVLangChangeCommand 不是 NVDA LangChangeCommand 子类；语言检测可以后置到 SynthDriver.speak，英语默认声音也可把后续汉字路由给中文声音。

固定 [WorldVoice 6.2](https://github.com/tsengwoody/WorldVoice/releases/tag/6.2) 提交 318bc90bf8a7af9e901bb43cd7da036533f443ea，核对 [pipeline](https://github.com/tsengwoody/WorldVoice/blob/318bc90bf8a7af9e901bb43cd7da036533f443ea/addon/synthDrivers/WorldVoice/pipeline/__init__.py)、[SynthDriver](https://github.com/tsengwoody/WorldVoice/blob/318bc90bf8a7af9e901bb43cd7da036533f443ea/addon/synthDrivers/WorldVoice/__init__.py)、[languageDetection](https://github.com/tsengwoody/WorldVoice/blob/318bc90bf8a7af9e901bb43cd7da036533f443ea/addon/synthDrivers/WorldVoice/languageDetection/__init__.py)。

新版缓存非 list 输入，失败时不返回耗尽的 generator。实际 Voice 解析之后才做普通话改写，早期公共 Filter 不重复改写中文。适配只包装 WorldVoice 模块局部的 lang_cmd_to_voice，校验签名、尊重字符模式、保持词典顺序、保护其他包装器、退出恢复；通过 NVDA 公共 synthChanged 管理生命周期。不修改 WorldVoice 文件、词典、Voice 实例或 NVDA 核心方法。

WorldVoice 暂无公有的后置读音扩展，因此这个窄私有适配仍需随未来版本维护。当前机器没有安装 WorldVoice。测试真实 upstream 模块和原始 speak 方法体，但隔离配置、日志、引擎发现和声音，未完成安装后的实际声音试听。

## 权威性与学术依据

[Unicode UAX #38 / 17.0.0](https://www.unicode.org/reports/tr38/tr38-39.html) 说明字音受词语、上下文、时代和地域影响；Unihan 是有来源的字符属性集合，不是全句消歧答案。kMandarin 首项也不是所有 TTS 的实际默认音。

[CC-CEDICT](https://www.mdbg.net/chinese/dictionary?page=cedict) 提供开放、可机器读取且许可明确的词级拼音，但并非国家语言主管机关认证的全语境标准库。本版保留下载文件明确的 CC-BY-SA-4.0 许可；不因为某个代码仓库声称 MIT 就把混合来源数据改成 MIT。教育部辞典用于个别词语交叉核对，例如[仙樂 xiān yuè](https://dict.concised.moe.edu.tw/dictView.jsp?ID=27272&la=0&powerMode=0)，没有把台湾辞典整体当作大陆普通话的强制规范。

学术方法依据（阅读公开摘要、项目说明及公开测试数据；未声称复现模型）：

- Park & Lee，Interspeech 2020，[g2pM / CPP](https://arxiv.org/abs/2004.03136)：句子级公开基准说明不能把词表规模代替语境准确率。本项目使用其 CPP test 做审计，不运行神经模型。
- Chen 等，Interspeech 2022，[g2pW](https://arxiv.org/abs/2203.10430)：上下文表示结合词性等信息，说明局部词条不足以覆盖所有消歧。未捆绑其模型或许可未确认的文件。
- Zhang 等，Interspeech 2023，[CVTE-Poly](https://www.isca-archive.org/interspeech_2023/zhang23h_interspeech.html)：需关注标签质量、读音分布和长尾，不能仅报一个总体准确率。
- Gao 等，NAACL 2024，[DLM](https://aclanthology.org/2024.naacl-long.294/)：分离表示/分类学习及局部到全局上下文改善长尾消歧；摘要报告 CPP 99.07%，不是全部中文场景百分之百，更不是本插件准确率。

因此实时读屏不加入网络或大模型推理；离线发现候选，经来源、正反例和声音适配审阅后编译。没有发现能合法获取且权威地解决任意语境的完整数据库。

## 数据、规则与审计反馈

快照 CC-CEDICT 2026-09-07、Unihan 17.0.0 固定哈希。109,673 词头中 88,485 可注音、21,188 阻断；882 个多读音目标字，427 个符合当前自动替换策略，4,580 个词头含可渲染非默认候选。这些是结构统计，不是引擎错误数量。

导入器检查同词全部候选，阻断专名、同词异读、对齐失败、缺少字音依据和轻声语法风险。空值是阻断词，不丢弃后再错误匹配短词。双向最长匹配需在原文同一区间一致；最大词长 32，有界索引，无朗读时 I/O。此算法仍是启发式，不能排除全部跨词语义歧义。

先形成原文 ReadingDecision，再由后端输出，语音同音字与盲文点位分离。既有六字族保护/禁用保持独立。新模板只有一个目标，字面文本及有限占位符；同级异读冲突弃权。

首次 CPP 探索审计 10,254 项：判断 3,639 项，其中与标注一致 3,503、不一致 136；弃权 6,615。主动替换候选 574 项中 27 项不一致。不能把所有差异推给数据集，也不能把弃权计作正确。据此扩展库默认关闭，明确音乐词语作为默认审阅模板。最终数字见 artifacts/cpp-evaluation.json。

没有针对测试集逐句补丁。报告仅记录行号、目标和读音差异，不复制原句。此次审计用于方案选择，所以后续声称独立质量提升需要额外冻结评估集；还需注意标注错误、地域读音及词汇来源重叠。条件一致率不能与强制每项作答的神经模型直接比较。

## 国家通用盲文

依据教育部 [GF 0019-2018](https://www.moe.gov.cn/jyb_sjzl/ziliao/A19/201807/W020180725666187054299.pdf)，视觉核对声母、韵母、声调、省调、简写和分词连写相关页面。正确拼音只是输入，正式盲文还需规则；例如 yuè 的全标调注音与零声母省调输出不是同一个格串。

两层实现：共享注音 API 保留原字、拼音、来源和 code-point/UTF-16 偏移，未知区间不猜；通过 NVDA 公共 brailleTables manifest 注册可选静态表，沿用 zhcn-cbs.ctb，用单目标 noback match 增加 418 个固定上下文（219 纠正、199 保护）。新省调读音必须显式审阅，否则构建失败。

不设置 outputForLangs，不改默认表，不支持反译，不改写 Region.update 或 louisHelper.translate。基础表更长词可能优先，已有整词路由合并保留；原生测试检查新点位、不丢失原来可独立定位的位置，而非虚构逐字路由。动态数词、用户设置、扩展大库未编入静态表；完整语法分词/国家通用盲文全条款未宣称实现。
